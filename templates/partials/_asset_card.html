{% load i18n %} {% comment %} One card on the board. Takes `card` (a `board.Card`), and the filter the screen is under so the reorder posts come back to the same tab. Everything on it has already been resolved by `board.cards_for` — which pins apply to this kind of machine, whether the plate is worth a row, how many codes are standing. A template asking whether a mower has a plate is the rule living in the one place nobody can test it. The nickname is not a pin and never becomes one: it is the link's accessible name, and a card that could switch it off would be an unlabelled link to somewhere (§9.5). The colour is decoration. It is a stripe and a tint, never the only thing saying something — the status pill, the due badges and the code count each carry their own words, so somebody who cannot distinguish these loses a recognition aid and no information at all. {% endcomment %}
