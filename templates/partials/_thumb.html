A click means two different things and the difference is the file, not the screen, so it is decided here too: * **A photograph enlarges in place.** `lightbox.js` intercepts the click and opens it over the page, which keeps the record it belongs to behind it — leaving the page to look at a photo and pressing Back was the old behavior and it lost your place on a long work order every time. * **A document opens in a new tab.** A PDF receipt is read, scrolled and searched; that is a job for the browser's own viewer, and it wants its own tab so the work order is still there when it is closed. The `href` is the file either way, so with JavaScript blocked every tile is still a working link to what it shows. That is the whole arrangement: the lightbox is an enhancement of a link that already went somewhere useful. {% endcomment %} {% firstof alt media.original_filename as label %}
