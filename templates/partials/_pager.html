{% load i18n %} {% comment %} Page numbers under a list that has more than one page, and a count on every one of them. The count is the part that matters. A list that silently stopped at two hundred rows looked exactly like a shop that owned two hundred parts, and the only way to discover otherwise was to go looking for something that should have been there. Saying how many there are costs one line and makes the truncation visible rather than invisible. Any other query the page carries — a search, a filter — is preserved, so paging through search results does not quietly drop the search.
