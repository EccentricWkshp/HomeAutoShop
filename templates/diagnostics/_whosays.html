{% load i18n %} {% comment %} Who says so, beside a trouble code's meaning. Takes `meaning` (a `dtc.Definition`) and optionally `printed` — the wording the scan tool itself put on that reading. A definition is only as good as whoever issued it, and these are not equal claims: SAE defines a generic code identically for every vehicle ever built, a manufacturer's list is that manufacturer's own wording, a note is one person in this shop, and a scan tool is a third party rendering somebody else's definition. Shown flat, the weakest of those reads exactly like the strongest. When the tool's own wording lost the ranking it is still printed underneath. It is what the tool actually said, and dropping it would edit the record on the reader's behalf — which is the opposite of the point. {% endcomment %} {% if meaning.source == 'operator' %} {% translate "· recorded here" %} {% elif meaning.source == 'make' %} {% blocktranslate with make=meaning.make %}· {{ make }}'s own list{% endblocktranslate %} {% elif meaning.source == 'report' %} {% translate "· as the tool read it" %} {% elif meaning.source == 'structure' %} {% translate "· nobody has said what this one is" %} {% endif %} {% if printed and meaning.source != 'report' and printed != meaning.text %}
